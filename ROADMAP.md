# Project Roadmap & Future Features

## Phase 2: AI & Automation

### 1. AI WhatsApp Notifications (Pending)
- **Feature**: Automatic absence notifications for parents.
- **Workflow**:
    1. Teacher marks student as **Absent** in the Class Journal.
    2. System triggers an AI prompt (e.g., GPT-4) to generate a friendly notification message.
    3. The message is sent via WhatsApp API to the parent's phone number.
- **Goal**: Increase transparency and parent engagement.

### 2. Performance Analytics
- AI-generated monthly reports for students based on their Journal scores.
- Predictive analysis for potential dropouts.

### 3. Financial Automation
- Automatic invoice generation and WhatsApp payment reminders.

*Note: These features are scheduled for the next development sprint.*
